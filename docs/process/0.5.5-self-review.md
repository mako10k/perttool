## 1. Decision

The complete `PTGOV-104` source change is suitable for a backward-compatible
`0.5.5` patch release. No blocking correctness, compatibility, package, or
release-safety finding remains.

The warning is emitted only after a valid candidate has been classified with
`applicable=true`, `intent="preview"`, and a non-empty `acceptedByOwner` set.
It exposes a caller that skipped the assertion-free first preview without
changing the candidate, GovernanceDecision v1, `writeAuthorized`, or
persistent authority.

## 3. Threat and scope review

The observed problem is accidental carryover of a loose owner-confirmation
assertion and expansion of its intended scope, not malicious evidence
forgery. The original 10 governed invocations contained five previews and
five persistent attempts. Every governed preview already carried the
assertion, so PTGOV-104 directly detects those five preview violations.

The warning intentionally does not classify the five persistent attempts. A
single persistent GovernanceDecision cannot distinguish an unchanged,
explicitly confirmed assertion from cross-candidate reuse. This patch does not
add accepted scopes, approval evidence, authentication, signatures, durable
audit, or cross-candidate state.

acceptance, Git push, annotated tag, GitHub prerelease, npm `beta`

GitHub Release, and `perttool@0.5.5` are absent. npm reported
