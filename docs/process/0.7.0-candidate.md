## 1. Correction boundary

This record rejects the preliminary local `perttool@0.7.0` tarball and accepts
one corrected replacement after it passed the complete gate.
The preliminary bytes passed technical package checks, but their bundled
README still asserted the preparation-time fact that no candidate had been
accepted. That transient statement would become false at candidate acceptance
and was therefore not suitable for an immutable public package.

It does not authorize or perform a Git push, tag creation, GitHub Release,
npm publication, npm dist-tag mutation, durable public acceptance, plan
advance, or Issue mutation. Neither the rejected preliminary copy nor its
accepted replacement is a public artifact.
