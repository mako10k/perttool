## 1. Frozen baseline

The isolated hotfix worktree descends from the exact commit shared by
`origin/main` and peeled annotated tag `v0.9.3`. npm reported `beta=0.9.3`,
`latest=0.9.0`, no `alpha`, and no published `0.9.4`; GitHub and Git had no
`v0.9.4` Release or tag.

The baseline exposes Grammar 7, CLI Contract 8, 53 commands, 23 root schemas,
129 root and Node runtime exports, and 45 Core runtime exports. These identities
are compatibility constraints for the patch.

## 2. Direct reproduction and RCA

The exact Issue #19 shape reproduced on the baseline: a completed edge reaches
a milestone while another live edge still owns that milestone. The provisional
advance retained the milestone but deleted its criterion set because the
contraction used `stateChangedMilestoneIds` as the retention proxy. The
emitted source then failed `document check` with `PTMAC-102`.

The llmthink RCA separates the initiating model defect from the missing final
candidate validation and the diagnostic-composition gap. No consumer plan was
edited, no force boundary was widened, and no history guard was bypassed.

## 3. Compatible patch decision

Suffix-free `0.9.4` is the narrow compatible patch. The correction restores
the already active Contract 8 behavior and does not change grammar syntax,
commands, schemas, result identities, authority, persistence, or force
semantics. A minor or contract-version change would overstate the boundary.

The release may move only npm `beta`. npm `latest`, public VSIX publication,
and unrelated plan advances remain separate decisions.
