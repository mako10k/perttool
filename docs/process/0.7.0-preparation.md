## 1. Accepted boundary

This record accepts the local version-bearing source preparation for the
first Grammar 6 and CLI Contract 7 package. It does not accept an immutable
candidate and does not authorize or perform a push, tag, GitHub Release, npm
publication, npm dist-tag mutation, plan advance, or Issue mutation.

The prepared source identifies itself consistently as `0.7.0` in the
manifest, both root lockfile entries, CLI version, changelog, README, tests,
goldens, and installed-package workflow. Published npm `beta`, npm `latest`,
and unqualified installation remain at `0.6.0` until a separately authorized
publication changes only the selected channel.

## 2. Migration and compatibility review

The accepted migration guide must cover the command, JSON, TypeScript,
grammar, governance, recommendation-authority, advance, Mermaid, exact-pin,
and rollback boundaries together. It must preserve Grammar 1 through 5 reads,
keep assurance opt-in, distinguish raw recommendation from start authority,
and avoid describing SHA-256 commitments as signatures or authentication.

The package remains beta-only through `publishConfig.tag=beta`. The retired
`alpha` channel is not recreated, and preparation does not move `latest`.
