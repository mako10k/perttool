# `v0.10.1` Compatibility Self-review

Date: 2026-08-20

The exact baseline is published `perttool@0.10.0`, release tag `v0.10.0`, and
the accepted local Issue #22 correction commit `ba54327`. npm readback reports
`beta=latest=0.10.0`; version `0.10.1`, its Git tag, and GitHub Release are
unused.

Issue #22 is a patch-level public routing defect. Contract 9 replaced the
Grammar 7 migration target with Grammar 8 even though `dag advance` still
requires Grammar 7 and the Grammar 8 planner accepts Grammar 7 input. The
correction exposes the retained implementation and fixes discovery/result
envelope consistency without changing either migration model.

The following public identities remain fixed: Grammar 8, CLI Contract 9, 56
commands, 23 root schemas, 129 root and Node runtime exports, and 45 Core
exports. `Perttool.MilestoneAcceptanceMigrationResult.v1` and
`Perttool.UnitMigrationResult.v4` remain distinct existing schemas; discovery
now truthfully lists both for the target-selected command.

Suffix-free `0.10.1` accurately represents this backward-compatible bug fix.
A minor version would overstate the boundary, while retaining `0.10.0` would
make the published package indistinguishable from the broken route.
