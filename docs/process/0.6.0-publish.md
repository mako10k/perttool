## Pre-publication CI correction

The first push of candidate-acceptance commit
`0806f8ff96e11011220df3b7439114058e63e396` triggered repository-check run
`30630708168`. Both Node.js 22 and 24 stopped at the same test before any tag,
GitHub Release, or npm publication. A fresh checkout builds `dist/cli.js` with
mode 0644, while the repository-clean candidate checker directly spawned that
path and received EACCES. The local preflight had reused a mode-0755 generated
file, so it did not expose the CI-only assumption.

The correction makes the checker invoke its supplied JavaScript CLI through
the active Node runtime and covers the case with a mode-0600 wrapper. The
checker and regression test are repository-only files, so the accepted npm
package tree and retained tarball remain byte-identical. Corrected commit
`935b097420d93597b17819a210e588553b1a4c06` passed both CI jobs before the
tag, GitHub Release, or npm publication was created.
