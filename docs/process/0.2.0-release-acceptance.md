## 1. Decision

Accept `v0.2.0` as the first published CLI Contract 3 package. The release was
accepted from npm `beta` and as a GitHub prerelease while npm `latest` remained
on Contract 2 `0.1.0`. After acceptance, the user separately authorized one
dist-tag operation that promoted `perttool@0.2.0` to `latest`; both npm
`beta` and `latest` now resolve to Contract 3 `0.2.0`.

This acceptance covers the registry-driven CLI and help surface, separate
domain guide and AI agent guidance, source-preserving file-first maintenance,
project initialization and metadata maintenance, direct gate maintenance,
atomic batch mutation, `dag next` v3, and the Node.js 22 runtime baseline. It
does not accept Issue #3, the LSP server, VSIX, MCP server, runtime i18n, human
override apply, durable audit, or Git integration.
