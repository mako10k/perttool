## 1. Selected boundary

The plan selects suffix-free `0.10.0` as the first Grammar 8 and CLI Contract
9 public package after `0.9.4`. `0.9.5` would understate the breaking grammar,
command, result, schema, migration, and temporal-authority boundary, while
`1.0.0` remains reserved for a future stable-series decision under ADR 0003.

The selected release input is the accepted calendar-aware temporal scheduling
workstream and its atomic Contract 9 public integration. The boundary contains
56 commands, 23 active root schemas with seven replacement result roots, 129
root and Node runtime exports, 45 Core runtime exports, and unchanged
`Perttool.AdvanceResult.v3`.

Private LSP, VSIX, and MCP workspaces remain excluded from the public npm
tarball. Public VSIX publication, npm `latest`, plan advance, and Issue
mutation remain separate.

## 2. Plan structure

The plan contains six serial tasks totaling 22p:

1. gate design fixes versioning, compatibility, migration, acceptance, and
   exclusion boundaries;
2. input readiness verifies the completed parent and detail temporal plans;
3. source preparation aligns every version-bearing artifact and runs complete
   local and installed-package gates;
4. candidate acceptance commits and freezes one clean immutable tarball after
   availability and route preflight;
5. PUBLISH performs only a separately authorized exact Git, GitHub prerelease,
   and npm `beta` batch; and
6. durable acceptance independently verifies public identity, behavior, and
   the exact `0.9.4` rollback pin.

Engineering, review, release-document, package, and external-release resources
serialize the relevant boundaries. Initial complete NextResult v8 recommends
and makes startable only `RELEASE_0100_GATE_DESIGN`.
