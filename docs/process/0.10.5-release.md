## Decision and scope

Select suffix-free `0.10.5` as a compatible patch after published `0.10.4`.
The release makes the Issue #23 `replan_and_reseal` action executable for a
newly added unsealed task in an already enabled assurance model. Atomic initial
enablement, dependency closure, governance, persistence, and public identities
remain unchanged.

Grammar 8, CLI Contract 9, 56 commands, 23 root schemas, 129 root and Node
runtime exports, and 45 Core exports remain unchanged.

## Publication gate

Freeze one clean source commit and tarball, pass the complete Node.js 22 gate,
prove exact installation and unused external identities, then push the exact
commit and annotated tag. Require Node.js 22 and 24 CI, create one GitHub
prerelease, and publish the identical tarball once to npm `beta`.

npm `latest`, Issue #23 mutation, release-plan advance, public VSIX
publication, and unrelated work remain separate.
