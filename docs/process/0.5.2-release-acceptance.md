## 1. Acceptance decision

Accept suffix-free beta `0.5.2` as a backward-compatible Grammar 5 and CLI
Contract 6 patch. All five release-plan tasks and 17p are complete over one
active day. Git commit `3f7cc04a47677f1db62e82830af3ea96a22b2d92`
preserves the exact completed pre-advance snapshot at source digest
`sha256:0d8963c423263b52e04d86f9af2dc11ed525f170eabee1d98e9e92e79a624223`.
Canonical governed advance then retained only reached milestone
`RELEASE_052_ACCEPTED` at source digest
`sha256:9f6c289d1211fc0d7951180b4fb6f2bf092b58e8744ae93c384cd51bcd72821f`.
Precedence and heuristic resource makespans remain zero, and complete
NextResult v5 has no ready, recommended, or startable task.

The version is a patch because it corrects the bundled JSON Schema
descriptions and adds opt-in schema projections without changing runtime
results. Grammar 5, CLI Contract 6, all 34 command operations, all 116 public
runtime exports, result identities, normalized payload meanings, default full
lookup semantics, and the original default query projection remain
compatible. No Contract 7 or Grammar 6 boundary is introduced.
