complete local gate. Release metadata changes only the CHANGELOG date and
removes the transient source-preparation wording from README. Grammar 10,
CLI Contract 11, public catalogs and all authority boundaries remain unchanged.

version-bound Override artifact. Hosted Node.js 22/24 checks must pass for the
exact release source before publication.

## Distribution sequence

1. Commit the release metadata after focused verification. Fast-forward only
   the reviewed preparation and release commits to origin/main.
2. Build and retain one tarball outside the checkout. Capture source commit,
   complete inventory, size, SHA-1, SHA-256 and npm integrity; run the isolated
   package workflow against those exact bytes.
3. Verify the exact source's hosted Node.js 22/24 checks and unused tag,
   GitHub Release and npm version. Create the annotated v0.12.1 tag at that
   source commit, push it and independently read it back.
4. Create one GitHub prerelease with that tarball and SHA256SUMS; download
   the hosted asset and verify byte identity.
5. Publish that same tarball once to npm beta through process-scoped
   NPM_TOKEN and GH_TOKEN injection. Read back registry metadata and bytes,
   exact/beta installations and rollback installation. Resolve an ambiguous
   response by readback, without repeating publication.
6. Record exact source, tag, CI, GitHub, npm and artifact evidence after
   independent distribution verification.

The observed pre-release channels are beta=latest=0.12.0 with no alpha.
Publication preserves latest=0.12.0. Latest promotion, Issue writes, public
VSIX publication and plan advance remain separate actions.
