# Migrating from `0.9.4` to `0.10.0`

`0.10.0` changes the public source and result boundary from Grammar 7 and CLI
Contract 8 to Grammar 8 and CLI Contract 9. Existing Grammar 1 through 7
documents remain readable. Consumers that bind JSON result identities or the
command catalog must adopt the Contract 9 replacements atomically.

## Source migration

Preview migration before writing:

```sh
perttool document migrate PLAN.pert --target-grammar 8 --diff
perttool document migrate PLAN.pert --target-grammar 8 --write \
  --expect-digest sha256:CURRENT_SOURCE_DIGEST
```

Grammar 7 `not_before` task fields become Grammar 8
`when start earliest` constraints. Calendar, availability, and temporal
constraint declarations remain source owned. A plan that uses plan assurance
must complete the separately required hash-model-2 initialization rather than
inferring new assurance evidence during migration.

Grammar 6 plans still require the committed Grammar 6 to 7 migration proof
before Grammar 7 to 8 migration. Neither migration bypasses milestone
acceptance, governance, history safety, or safe-write checks.

## Result identities

Adopt these replacements together:

| Contract 8 | Contract 9 |
| --- | --- |
| `Perttool.ProjectResult.v4` | `Perttool.ProjectResult.v5` |
| `Perttool.CheckResult.v5` | `Perttool.CheckResult.v6` |
| `Perttool.AnalysisResult.v6` | `Perttool.AnalysisResult.v7` |
| `Perttool.NextResult.v7` | `Perttool.NextResult.v8` |
| `Perttool.MutationResult.v5` | `Perttool.MutationResult.v6` |
| `Perttool.PlanAssuranceResult.v1` | `Perttool.PlanAssuranceResult.v2` |
| `Perttool.UnitMigrationResult.v3` | `Perttool.UnitMigrationResult.v4` |

`Perttool.AdvanceResult.v3` is unchanged. The command catalog grows from 53 to
56 paths; the active command-result root count remains 23 through replacement.

## Compatibility and rollback

Use exact `perttool@0.9.4` as the rollback pin for Grammar 7 and CLI Contract 8
workflows. Do not write a Grammar 8 document with the rollback version. Private
LSP, VSIX, and MCP workspaces are not included in either public npm tarball.
