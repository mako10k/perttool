# 0.11.1 to 0.12.0 consumer migration

Date: 2026-09-30
Status: Local source preparation; 0.12.0 is not yet published
Authority: Plan Review Request Normative 1.0, sections 4, 8, 9, 10 and 12

## Documents and package consumers

Existing Grammar 1 through 9 documents remain readable. Explicitly migrate a
valid Grammar 9 document with `perttool document migrate PLAN.pert
--target-grammar 10` before creating or inspecting Plan Review requests.
Earlier grammars follow the existing migration path to Grammar 9 first.
Preview migration and use the command's standard write controls for adoption.
There is no automatic downgrade. The exact 0.11.1 rollback package does not
read Grammar 10 documents; retain a pre-migration document if rollback is needed.

CLI Contract 11 adds `plan-review create`, `list`, `show` and `resolve`.
These operations require Grammar 10 and reject older input with `PTREV-110`.
Resolution composes one normalized existing batch request and retains ordinary
validation, governance, assurance, history, warning and safe-write guards.
It is not an automatic approval or an authorization bypass.

## Next and schema consumers

Replace `Perttool.NextResult.v8` consumption with `Perttool.NextResult.v9`.
The complete `plan_review` projection is available for every supported
Grammar 1 through 10 input and precedes the operational recommendation.
For older grammars it is `clear` with no requests. The text form emits a
`PLAN_REVIEW` line containing the complete JSON projection before the
recommendation; consumers of exact text should account for this line.

Discover the closed `Perttool.PlanReviewResult.v1` and
`Perttool.PlanReviewMutationResult.v1` schemas rather than inferring fields.
The current catalog has 31 root schemas. Package root and Node have 155
runtime exports; portable Core remains at 51. Existing recommendation,
start authority and Plan Review state must be interpreted independently.

## Verification before switching

Use the retained package's installed acceptance workflow to check Grammar 9
migration, unchanged older-document operational Next meaning, all seventeen
normative acceptance groups, input limits and real persistence races. Switch
exact or beta installations only after the distributable is accepted and
published; a local source version does not establish registry availability.
