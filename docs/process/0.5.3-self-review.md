## 1. Decision

The complete source change is suitable for a backward-compatible `0.5.3`
patch release. No blocking correctness, compatibility, package, or release
safety finding remains.

The patch publishes two already accepted maintenance changes:

- npm publication supports only the maintained `beta` channel and rejects an
  alpha artifact before registry mutation; and
- loose `--accepted-by-owner` confirmation is caller guidance for one
  unchanged candidate and its explicitly named affected scopes, never
  workstream, session, or later-command authority.

The review also found that raw digests were a poor primary explanation for a
human confirmation decision. The source now requires the caller to lead with
available modification time, exact UTF-8 byte sizes, diff counts, and semantic
changes. Source and candidate digests remain supplemental machine identity.

## 3. Review findings

The review identified and corrected these non-malicious caller hazards:

1. a loose owner assertion could become command boilerplate;
2. a general release instruction could be widened to a later `dag advance`;
3. an assertion used on not-applicable maintenance hid its real scope;
4. one confirmed candidate could be reused for a changed or later candidate;
   and
5. digest-first confirmation text did not explain the actual change to a
   person.

The accepted six-case controlled run showed an assertion-free preview,
assertion-free ordinary maintenance, one confirmed advance, no carryover to
the second advance, complete goal-and-DAG scope naming, and rejection of scope
widening by candidate replacement. The human projection correction does not
add a new CLI field; it fixes the bundled caller workflow and Guide.

## 4. Release safety

The user selected release work after asking for a release judgment. The named
authorization covers `0.5.3` preparation, candidate acceptance, Git push,
annotated tag, GitHub prerelease, npm `beta` publication, and durable
acceptance after predecessor gates pass. It does not cover npm `latest`.

External preflight on 2026-07-30 established that local and remote `v0.5.3`,
the GitHub Release, and `perttool@0.5.3` are absent. npm reported
`beta=0.5.2`, `latest=0.5.1`, and no `alpha` dist-tag.
