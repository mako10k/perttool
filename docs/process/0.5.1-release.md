## 1. Decision and scope

Select suffix-free `0.5.1` for the compatible CLI Contract 6 and Grammar 5
patch that publishes:

- the read-only `schema [schema-id]` command;
- bundled Draft 2020-12 artifacts for every active command result and the
  supported library-only OverrideDecision result;
- package-root catalog and lookup APIs plus the `perttool/schemas/*` export;
  and
- Git 2.54 strict UTC `Z` commit-time compatibility.

The patch retains existing commands, options, Grammar 5 meanings, result
identities, payload meanings, exit meanings, and exports. It does not create
CLI Contract 7, Grammar 6, an MCP schema contract, runtime i18n, a stable
series, or an npm `latest` promotion. Issue #5 closure remains separate.

## 2. Work packages and authority

The dependency order is fixed by `plans/release-0.5.1.pert`.

1. `RELEASE_051_SELF_REVIEW` verifies compatibility, the complete source
   change, CI root cause, package boundary, and release safety.
2. `RELEASE_051_PREPARATION` aligns version-bearing source, release
   documentation, self-use checks, tests, and goldens.
3. `RELEASE_051_CANDIDATE` accepts one clean commit and one immutable
   tarball after complete local and read-only external preflight.
4. `RELEASE_051_PUBLISH` pushes the release commit and annotated tag, creates
   the GitHub prerelease, and publishes the same tarball once to npm `beta`.
5. `RELEASE_051_ACCEPTANCE` records durable identity and public-channel
   verification.

The user's 2026-07-30 instruction authorizes this complete named sequence once
every predecessor gate passes and no blocking self-review finding remains.
It does not authorize npm `latest` promotion, Issue #5 closure, or a different
version, tag, artifact, or publication channel.
