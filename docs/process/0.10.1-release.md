- Status: Local release gate accepted
- Decision date: 2026-08-20
- Target version: `0.10.1`
- Product maturity: beta
- GitHub channel: prerelease
- npm publication tag: `beta`
- Versioning: [ADR 0003](../adr/0003-beta-versioning.md)
- Release plan: [`release-0.10.1.pert`](../../plans/release-0.10.1.pert)
- Accepted input: [`issue-22-migration-path-acceptance.md`](issue-22-migration-path-acceptance.md)

## Decision and scope

Select suffix-free `0.10.1` as a compatible patch after published `0.10.0`.
The release restores the existing repository-bound Grammar 7 migration route
to Contract 9 discovery and validation, advertises both migration result
identities, and returns the active Contract 9 envelope for Grammar 7 results.

Grammar 8, CLI Contract 9, 56 commands, 23 root schemas, 129 root and Node
runtime exports, and 45 Core exports remain unchanged. The implementation does
not alter either migration planner, `dag advance`, governance, history proof,
safe writes, adapters, or private-workspace distribution.

## Gates

1. Self-review compares exact published `0.10.0` behavior and the accepted
   Issue #22 correction and performs no external write.
2. Preparation aligns every version-bearing surface and passes the complete
   Node.js 22 repository and installed-package gate.
3. Candidate acceptance starts from committed clean source, freezes one
   immutable tarball, proves version and route availability, and verifies exact
   installed behavior without publishing.
4. PUBLISH consumes only the owner-authorized candidate, pushes the release
   commit and annotated tag, requires Node.js 22 and 24 CI, creates one GitHub
   prerelease and checksums, and publishes the identical tarball once to npm
   `beta` through `secdat`.
5. Durable acceptance independently reads back every identity and behavior.

## Separate boundaries

npm `latest` remains unchanged unless separately authorized. Issue mutation,
public VSIX publication, release-plan advance, and unrelated work are not part
of this release batch.
