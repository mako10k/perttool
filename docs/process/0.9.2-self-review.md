identifies a patch after `0.9.1`; a minor version would overstate the boundary.

intended nullable forecast and unavailable temporal facts. Grammar 7, CLI
Contract 8, 53 commands, 23 root schemas, 129 key- and reference-identical root
and Node runtime exports, 45 Core runtime exports, result and schema
