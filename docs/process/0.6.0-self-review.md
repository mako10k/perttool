## 1. Decision

Accept the source boundary for preparation as suffix-free beta `0.6.0`.
`0.5.6` would understate the existing-command result-identity and persistent
write-safety change. Contract 7 or Grammar 6 would overstate the retained
command, grammar, and non-advance result surface.

No blocking correctness, compatibility, packaging, or release finding remains
before source preparation. Publication remains gated by a clean prepared
commit, complete Node.js 22 checks, one immutable candidate, unused external
identities, protected routes, and the user's named release authorization.
