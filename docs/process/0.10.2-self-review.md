# `v0.10.2` Compatibility Self-review

Date: 2026-08-21

The exact baseline is published `perttool@0.10.1`, release tag `v0.10.1`, and
the accepted local Issue #20 correction commit `d1790d1`. npm readback reports
`beta=0.10.1` and `latest=0.10.0`; version `0.10.2`, its Git tag, and GitHub
Release are unused.

Issue #20 is a patch-level historical classification defect. An unchanged
retained assurance receipt can refer to a task producer removed by an earlier
canonical advance. When that producer is absent from both adjacent snapshots,
the receipt does not prove a frozen-plan change. The correction skips that
stable absence while retaining conflicts for one-sided presence, changed
receipts, and present frozen-task changes.

The following public identities remain fixed: Grammar 8, CLI Contract 9, 56
commands, 23 root schemas, 129 root and Node runtime exports, and 45 Core
exports. Historical result schemas, assurance identities, Git evidence limits,
authority, persistence, LSP, VSIX, and MCP boundaries remain unchanged.

Suffix-free `0.10.2` accurately represents this backward-compatible bug fix.
A minor version would overstate the boundary, while retaining `0.10.1` would
make the published package indistinguishable from the broken classification.
