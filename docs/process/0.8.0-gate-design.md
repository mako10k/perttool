- Document status: Accepted 1.0
- Decision date: 2026-08-07
- Task: `RELEASE_080_GATE_DESIGN`
- Target version: `0.8.0`
- Grammar: Grammar 6
- CLI contract: Contract 7
- Publication state: unpublished
- Release procedure: [`0.8.0-release.md`](0.8.0-release.md)
- Release plan: [`release-0.8.0.pert`](../../plans/release-0.8.0.pert)

## 1. Version decision

Accept suffix-free `0.8.0` for the additive public-package boundary after
published `0.7.1`. The current source adds a public command, result, schema,
and two library subpaths. `0.7.2` would understate that surface change, while a
new Grammar or CLI Contract would overstate the retained semantic boundary.

The package remains a pre-1.0 beta, uses a GitHub prerelease, and publishes
only to npm `beta`. Publication must leave independently managed
`latest=0.7.1` unchanged.

## 2. Fixed public surface

The gate fixes the following transition from the published `0.7.1` baseline:

| Surface | `0.7.1` | `0.8.0` target |
| --- | ---: | ---: |
| Grammar | 6 | 6 |
| CLI Contract | 7 | 7 |
| Commands | 44 | 45 |
| Root schemas | 20 | 21 |
| Root runtime exports | 121 | 122 |
| Node runtime exports | unavailable | 122 |
| Core runtime exports | unavailable | 45 |

The additive command is `dag history`; its result and root schema identity is
`Perttool.HistoricalGraphResult.v1`. The additive package paths are
`perttool/core` and `perttool/node`. Root and Node exports must be key- and
reference-identical. Core must remain platform-neutral and closed at 45
runtime values.

The release also includes `DECL-ID-001`, which corrects task selection and
insertion without changing syntax or valid existing source order.

## 3. Compatibility and exclusion boundary

The release retains existing Grammar 6, CLI Contract 7, command and option
meanings, prior result and schema meanings, governance decisions, conditional
plan assurance, recommendation and temporal start authority, history safety,
and source-preserving writes.

The private LSP, VSIX, and MCP workspaces remain build and acceptance inputs
but are excluded from the public npm inventory. The historical editor results,
compact/Dagre presentation, public VSIX identity, Marketplace and Open VSX,
editor mutation, MCP mutation, `SCM-001`, npm `latest`, plan advance, and Issue
mutation remain outside this release.

## 4. Authority and result

The user's 2026-08-07 release instruction authorizes this local gate and the
following local input, preparation, and candidate tasks. It does not authorize
PUBLISH before one immutable release commit, tarball, and external write set
are presented for candidate-specific confirmation.

This gate changes no package version, Git ref, remote, tag, Release, registry,
dist-tag, VSIX publication state, plan advance state, or Issue. Its successor
is only `RELEASE_080_INPUT_READINESS`.
