## 1. Decision and scope

Select suffix-free `0.6.0` for the accepted ADV-001 history-safety guard and
ADV-002 repository-clean candidate correction. The release keeps Grammar 5
and CLI Contract 6 while changing only `dag advance` to the new closed
`Perttool.AdvanceResult.v1` identity.

The release includes the exact read-only Git proof, stage-0 overlap and race
handling, human-readable guard evidence, `--force-history-loss`, complete root
schema and package API, and the one-candidate terminal-separator correction.
It does not include npm `latest` promotion, plan advance, Issue mutation, Git
mutation by the runtime, MIG-08, or general remove-command history guards.

## 2. Work packages and authority

The dependency order is fixed by `plans/release-0.6.0.pert`:

1. `RELEASE_060_SELF_REVIEW` accepts the minor-version, compatibility, safety,
   schema, TypeScript, migration, and release boundary.
2. `RELEASE_060_PREPARATION` aligns every version-bearing and installed surface
   and passes the complete Node.js 22 source gate.
3. `RELEASE_060_CANDIDATE` accepts one clean immutable tarball after unused
   identity, channel, route, and package verification.
4. `RELEASE_060_PUBLISH` pushes the accepted commit and tag, creates the
   GitHub prerelease, and publishes the exact tarball once to npm `beta`.
5. `RELEASE_060_ACCEPTANCE` independently verifies public identity and records
   durable acceptance.

The user's 2026-07-31 release instruction and exact release-plan confirmation
authorize this complete named sequence after every predecessor gate passes.
They do not authorize npm `latest` promotion, plan advance, or Issue mutation.

## 5. Publication gate

Publish only the accepted candidate:

1. use `secdat exec git push ...` for the clean release commit;
2. create and push annotated `v0.6.0` at that exact commit;
3. wait for Node.js 22 and 24 CI success;
4. create a GitHub prerelease with the retained tarball and `SHA256SUMS`
   through `secdat exec gh ...`;
5. download and install the GitHub asset in isolation;
6. inject `NPM_TOKEN` only into one `npm publish <retained-tarball> --tag beta`
   process through `secdat`;
7. do not retry an ambiguous publish; use registry readback until the one
   immutable publication resolves; and
8. verify `beta=0.6.0`, unchanged `latest=0.5.5`, and no `alpha`.

Record the exact mutation and readback in
[`0.6.0-publish.md`](0.6.0-publish.md).

because the repository-clean acceptance helper directly spawned a generated
mode-0644 `dist/cli.js` in a fresh checkout. The local generated file had mode
0755. The repository-only checker now invokes the supplied JavaScript CLI
through the active Node runtime, with a mode-0600 wrapper regression test. The
retained package bytes were unaffected; publication remained stopped until a
new clean commit passed Node.js 22 and 24.
