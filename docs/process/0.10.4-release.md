## Decision and scope

Select suffix-free `0.10.4` as a compatible patch after published `0.10.3`.
The release fixes Issue #6 by adding the explicit, auditable
`--history-provenance new-root` recovery while preserving automatic
fail-closed rename inference and all Git and mutation boundaries.

Grammar 8, CLI Contract 9, 56 commands, 23 root schemas, 129 root and Node
runtime exports, and 45 Core exports remain unchanged. The two existing
history result identities receive only additive required provenance metadata.

## Publication gate

Freeze one clean source commit and tarball, verify the complete Node.js 22
gate, exact installation, unused tag/release/npm version, and authenticated
routes. Push the exact commit and annotated tag, require Node.js 22 and 24 CI,
create one GitHub prerelease with the tarball and `SHA256SUMS`, publish the same
tarball once to npm `beta`, then independently read back every identity.

Issue #6 is closed only after durable release evidence is available. npm
`latest`, public VSIX publication, release-plan advance, `SCM-002`, and
unrelated work remain separate.
