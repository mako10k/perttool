# Migration from `0.8.1` to `0.9.0`

- Document status: Accepted 1.0
- Decision date: 2026-08-13
- From: Grammar 6, CLI Contract 7, `perttool@0.8.1`
- To: Grammar 7, CLI Contract 8, `perttool@0.9.0`

## Public compatibility boundary

`0.9.0` is a breaking beta minor. Machine consumers must accept CLI Contract
8 and the active versioned result identities. The command registry grows from
45 to 53 commands, the root schema catalog from 21 to 23, and root and Node
exports from 122 to 129. Core remains 45 exports.

Contract 8 uses `Perttool.CheckResult.v5`, `Perttool.AnalysisResult.v6`,
`Perttool.NextResult.v7`, `Perttool.MutationResult.v5`, and
`Perttool.AdvanceResult.v3`. Consumers must not reinterpret Contract 7 results
as these replacements.

## Document migration

Existing Grammar 1 through 6 documents remain readable for check, analysis,
Next, and committed migration. Milestone acceptance mutation and canonical
advance require Grammar 7.

Preview migration first:

```sh
perttool document migrate PLAN.pert --target-grammar 7 --format json
```

For a changed in-place migration, use a clean committed source and the returned
digest with the ordinary actor and owner-confirmation workflow. Migration
creates one exact grandfather baseline for milestones already declared
`state reached`. It creates no criterion, receipt, waiver, or inferred
acceptance.

After migration, declare a complete non-empty criterion set for each new
non-grandfathered milestone before canonical advance:

```sh
perttool milestone acceptance replace PLAN.pert MILESTONE --request criteria.json
perttool milestone acceptance show PLAN.pert MILESTONE --format json
```

Evidence, failure, unavailable, revocation, and waiver receipts use their
dedicated preview-first commands. Caller-provided verifier and timestamp values
are provenance assertions, not authentication or trusted time.

## Automation and rollback

Automation must require a complete known `Perttool.NextResult.v7`, complete
assurance, complete milestone-acceptance projection, and task IDs in
`startable_recommended_task_ids`. An unavailable or unsupported acceptance
projection fails closed.

Use exact `perttool@0.8.1` as the rollback pin for Grammar 6 and CLI Contract
7. A Grammar 7 document containing milestone-acceptance declarations is not
readable by that rollback package; retain the committed pre-migration source
for rollback.

Private LSP, VSIX, and MCP packages remain repository-only and are not public
npm migration targets.
