## 1. Acceptance decision

Accept `v0.5.4` as a backward-compatible Grammar 5 and CLI Contract 6 beta
patch. It adds runtime `PTGOV-103` visibility for a caller-supplied
owner-confirmation assertion on a valid governance-not-applicable mutation
candidate. Default write authority is unchanged; existing
`--warnings-as-errors` fails before persistence.

The release does not add a command, option, result identity, schema identity,
accepted-scope field, evidence field, authentication, cross-candidate state,
or npm `latest` promotion. It therefore retains the compatibility decision
recorded by the self-review.
