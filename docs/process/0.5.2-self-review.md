## 1. Decision

The complete source change is suitable for a backward-compatible `0.5.2`
patch release. No blocking correctness, compatibility, package, or release
safety finding remains.

The published `0.5.1` artifacts introduced machine-readable result schemas
but still allowed nested object placeholders with unspecified child fields.
That defect made the artifacts weaker than the existing closed runtime result
contracts. The correction enumerates the actual fields, required sets, enums,
and closed boundaries and validates representative real CLI and library
results. It does not change a runtime result payload.

The new schema display surface is opt-in. Existing
`perttool schema <schema-id> --format json` invocation, complete-artifact
selection, exit meanings, and `query: {schema_id}` projection remain. Explicit
`--view full` names the same complete artifact. `--view outline` returns a
shorter Draft 2020-12 projection with absolute bundled references, and
`--ref` selects one referenced detail layer.

## 3. Review findings

The review identified and corrected these issues before release selection:

1. nested bare `type: object` placeholders did not describe real result
   records;
2. nested records with properties were not uniformly closed or required;
3. a complete schema was too long for structural inspection;
4. local `$defs` could not be inspected independently through the command;
5. installed-package checks covered complete lookup but not outline/detail
   resolution; and
6. compatibility wording initially risked implying byte-identical schema
   content instead of stable lookup semantics.

The source now has a static negative-omission check for unspecified or
unclosed object schemas, nested unknown-field rejection, rich real-result
validation, strict outline compilation, full/default parity, local/Common
detail resolution, invalid-reference recovery, and installed-package
coverage.

to `0.5.2`.

7, Grammar 6, new runtime result identities, MCP/LSP/VSIX schemas, network
schema resolution, runtime i18n, automatic Git mutation, or human override
apply/audit.
