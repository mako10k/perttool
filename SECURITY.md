# Security Policy

## Supported versions

Only the latest published GitHub prerelease is maintained on a best-effort basis. Because it is a development preview, fixes may include incompatible changes.

## Reporting a vulnerability

Do not report vulnerabilities in public issues; report them privately through a [GitHub Security Advisory](https://github.com/mako10k/perttool/security/advisories/new).

Include the affected version, reproduction conditions, expected impact, and, where possible, a minimal reproducer. Do not attach credentials or third-party data.
