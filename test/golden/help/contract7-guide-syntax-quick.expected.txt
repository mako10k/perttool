DSL syntax

Grammar versions 1 through 6 for declaring projects, governance metadata, resources, milestones, tasks, gates, explicit task work events, and conditional plan-assurance records.

Declarations
Place exactly one project first, followed by resource, milestone, task, gate, and Grammar 5 work-event declarations. Grammar 6 additionally accepts task_relation, plan_seal, task_outcome, and assurance_receipt declarations.

Syntax:
  project ID:
  milestone ID:
  task ID FROM -> TO:
  gate ID FROM -> TO:
  resource ID:
  work_event ID:
