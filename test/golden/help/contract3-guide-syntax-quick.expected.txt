DSL syntax

Grammar version 1 for declaring project, resource, milestone, task, and gate.

Declarations
Place exactly one project first, followed by resource, milestone, task, and gate declarations.

Syntax:
  project ID:
  milestone ID:
  task ID FROM -> TO:
  gate ID FROM -> TO:
  resource ID:
